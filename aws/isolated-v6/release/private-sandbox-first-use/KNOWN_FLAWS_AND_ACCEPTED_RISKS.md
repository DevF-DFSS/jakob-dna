# Known flaws and accepted limits for a private synthetic TEST

Acceptable only after MVSU boundary gates pass: rough endpoint ergonomics, manual evidence gathering, partial dashboards/alarms, test-volume throughput, conservative 1 request/sec and burst 2 ingress throttling, application bugs confined to synthetic non-sensitive records, and inherited pinned-validator findings. A bootstrap stack contains no Lambda ResourcePolicy, so the stale ResourcePolicy E3006 finding does not by itself make an inert API/bucket create unsafe. PR15 registry evidence remains historical; refresh deployment-region schema before runtime creation. Do not suppress lint or call a failed CI workflow green.

Not accepted: broad legacy authority over V6, role reuse with table access, root as routine operator, first-write authority without a real principal, an editable/forged approval string, unbounded TEST capability, unsecured direct Lambda path, unverified JWT claims/provider profile, ability to skip CLOSED state, artifact/version mismatch, or a rollback/quarantine path that cannot be exercised.

Same-account root or sufficiently privileged administrators can replace policies. This is an explicit accepted *administrative* limitation of this proposed private sandbox, not evidence that ordinary legacy principal containment is unnecessary. Actual policy evaluation, Lambda source context, API Gateway projection and CloudFormation lifecycle are still B-class live tests. Provider selection, real bindings and exact approved subject/client IDs remain unknown. A new private bucket name was absent from this account's ListBuckets result; global availability is unverified until a separately authorized create attempt. No existing legacy resource is repurposed.

Cost: CloudFormation `AWS::*` has no additional orchestration fee; underlying resources may incur charges. The inert API has no stage/route and thus no intended calls, while HTTP APIs are billed by calls/data once used. The new bucket is initially empty, but S3 requests and later storage/versions can be billable. Estimate **negligible but potentially billable** at tiny controlled volume, not guaranteed $0. Sources retrieved 2026-09-27: [CloudFormation pricing](https://aws.amazon.com/cloudformation/pricing/), [API Gateway pricing](https://aws.amazon.com/api-gateway/pricing/), [S3 pricing](https://aws.amazon.com/s3/pricing/). Optional logs, alarms, identity provider, Lambda, DDB and retained artifacts need their own capped budget review before their respective later phase.
